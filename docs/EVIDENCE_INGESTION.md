# 原文定位与商城补充（2026-10-22）

首次创作与平台切换共用商城补充逻辑。原知识源仍是该任务选定的 ima 或 ZIP；缺少有效事实、检索需求未完全覆盖或图片低于平台硬性下限时，有限尝试华为商城。小红书3–6张为建议，不因建议数量补图或阻塞。商城不可访问时保留已有产品事实，普通缺项省略；真实身份/安全/必要兼容门槛、实际冲突、用户明确必须、零产品事实或硬性图片不足仍须处理。

`quote_evidence.locate` 仅接受空白、零宽排版符、全角ASCII及明确中英文逗号/分号等格式等价。定位后恢复为原文连续片段，记录原摘录、起止位置与原文摘要。小数点、数字、单位、负号、约/最高及配置条件不被忽略。最终 `verify_facts` 仍要求原文逐字支持。无法定位的卡尝试一次定向纠正；失败则隔离，覆盖引用同步降为partial/not_found，其他卡继续使用。

商城发现顺序：任务中的官方链接、`backend/vmall_products.json` 的可审计商品种子；仍无入口时再读取原知识源官方快照链接。种子不含产品参数或价格，不证明现售。每次读取仍核对精确型号、系统、代际与SKU；系列名、不同年份和不同系统不能互相替换。

商城采用匿名官方页面或公开商品数据，保留页面地址、实际取证地址、SKU、时间和原始JSON；正文使用可追溯的解码文本视图，避免JSON转义造成定位错误。仅增量提取新来源，原事实ID保留，新事实使用VM前缀；新图仍须画面核验。价格优惠仅在原需求明确请求时读取。

部署前任务与素材备份仅保存在忽略目录，不进入Git。`POST /api/maintenance/restore` 是默认关闭的一次性维护通道：必须单独配置至少32字符的 `HUAWEI_MAINTENANCE_KEY` 并提交 `X-Maintenance-Key` 请求头，备份最多20任务/80图片/40MB；严格验证素材路径、格式与摘要，不覆盖现有任务。导入使旧核验失效；成功后通道立即关闭，发布脚本随后删除临时密文变量。发布密钥不发送到应用域名。
