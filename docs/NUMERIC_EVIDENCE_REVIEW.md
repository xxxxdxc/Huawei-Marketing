# 数值核验规则：numeric_atoms_v1

原校验删除空白后，在全部事实quote拼接字符串中查找正文“数字+单位”，会误报`7.6/7.3 mm`中的`7.6 mm`，也可能把`7.6 mm`错匹配进`17.6 mm`。

现在逐张事实quote解析连续数值表达，保留事实ID和完整原quote。支持末尾共享单位的明确并列/尺寸链（`7.6/7.3 mm`、`310×222×13.5 mm`）、全角数字/点/斜杠/单位及Unicode空白、等值小数（`7.60=7.6`）。Decimal只用于精确十进制解析与格式统一，不做精度舍入；单位同义写法可归一，不进行kg→g等单位换算，不做乘法/除法计算。

不跨事实或跨句借单位，不用Fact.claim/conditions替代quote，不从分数推断并列参数。正文/图注只在本段声明的fact_ids内匹配；标题、导语、CTA和标签使用当前规划授权且成稿实际声明的事实。内部heading不作为公开文案检查。

每条数字匹配记录包含位置、规范化表达、数值/单位、引用事实、匹配事实及原quote/source_id，写入review.numeric_checks。未匹配问题定位到具体标题/段落/图注，说明引用范围。原始事实和稿件不因解析而改写。

数值匹配只证明数值与单位存在，不证明左右、展开/闭合、型号、配置、约值/最高/典型值或其他条件正确。独立Reviewer得到明确边界和数值记录，继续逐条语义核验。数值齐全但左右互换仍应由语义核验拒绝；消除格式误报不等于整篇自动通过。

专项：`backend/test_numeric_evidence.py`。截图稿离线复现及一次真实重验记录：`.local/numeric_review_evals/20261021_fold_recheck/`。真实重验使用原保存正文和事实，allow_repair=False，不调用Brief/Planner/Writer，保存新报告及历史版本。
