# 推文表达与内部提示分离

更新：2026-10-21。已按用户确认的 A/A 实施。仅在本地修改，未自动改写已有任务正文。

## 对外内容

- 段落 heading 保留为工作人员阅读提示和核验定位字段，不出现在三个平台的实际阅读预览、复制文案或 marketing.md 中。整篇文章 title 保留。
- 原文的“约”、版本、配置、适配条件、最高/典型值及必要测试口径，若影响所用结论，应自然、具体、简短地表达。不能为了简洁将有条件能力写成全型号能力。
- 制造/测量方式导致尺寸重量差异、泛泛的“以实际配置/购买版本为准”等不再作为新稿正文补丁。无法简洁准确表达的结论应放弃，或在该段已授权事实范围内选择其他内容。
- 最终行动引导只由根级 cta 承载；不额外规划纯CTA段，不在导语/正文/图注重复。旧规划的锚点和图片保留，必要时纯CTA段可以留空，不影响图片数量与顺序。

## 内部证据

Fact.conditions、quote、候选 conditions 和知识包不被删减。backend/publication_rules.py 为 Planner、Writer、Reviewer 和定向修订提供一致规则，并将事实条件整理成内部说明/实质条件提示；未分类或混合条件按实质条件保守处理。提示分类不替代原文，也不将未知条件当作可忽略内容。

候选卖点/规划仍只引用已核验事实和图片。Writer 与 Reviewer 能看到完整知识包，不因对外不显示通用说明就丢失证据；核验不再要求将所有原文条件逐句补回正文。

## 新旧稿行为

新写稿成功后标记 task.publication_policy_version=natural_copy_v1。该版本的新稿增加通用说明、内部提示泄露和重复CTA的程序检查，问题进入现有最多一次定向修订/完整复核流程；事实与图片核验职责不变。语义层面的条件完整性和同义重复仍由 Reviewer 检查，程序模式匹配不宣称覆盖所有变体。

旧稿即时采用不显示段落标题的新呈现规则，但原文、限定说明和CTA不被后台迁移或重写，也不自动触发模型调用。只有用户主动重新生成时使用新写法。旧稿重新核验时不因已有通用说明要求额外改写；历史版本恢复会带回其原本规则版本。人工编辑后重新核验和两次确认保持原样。

## 导出

单独 Markdown 和 ZIP 中 marketing.md 为对外文章：保留整篇标题、导语、段落正文、配图、CTA和标签，不附内部阅读提示、源文件路径、策略或证据报告。

ZIP 新增 evidence.md，保留原来的策略、事实原文、来源路径、完整条件和核验信息；review.json、layout.json、实际配图继续保留。工作人员也可在工作台“依据”查看证据。

## 验证范围

增加13项后端专项和5项浏览器验证，覆盖通用/必要条件区分、原证据不变、旧稿不改写、新稿定向修订、内部标题不参与消费者检查、三平台预览、真实复制按钮及独立证据导出。完整回归和构建结果见本轮交付说明。

这些测试使用隔离夹具，没有修改真实任务或调用付费模型。此前15例Planner盲评属于本次表达规则修改前的冻结版本；本次没有重跑该批真实模型对比，不将原评分作为新规则的质量证据。
